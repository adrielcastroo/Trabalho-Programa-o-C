## Tecnologias e Recursos Utilizados

* **Linguagem:** C (padrão ANSI / ISO)
* **Bibliotecas Principais:** `<stdio.h>` para entrada/saída e `<locale.h>` para o suporte de acentuação gráfica regional.
* **Compilador:** GCC (MinGW / Dev-C++)

\---

## Estrutura de Questões e Arquivos

Clique nos links abaixo para navegar diretamente até o código-fonte comentado de cada questão:

### Módulo 1: Tipos de Dados

* [**Questão 01 - Cadastro Simples**](questao_01.c)**:** Programa que declara variáveis dos tipos `int`, `float` e `char` para armazenar e exibir idade, altura e a inicial do nome.
* [**Questão 02 - Conversão de Tipos**](questao_02.c)**:** Leitura de dois inteiros para exibição de soma, divisão inteira e divisão real aplicando a técnica de *casting*.

### Módulo 2: Expressões, Operadores e Tabela Verdade

* [**Questão 03 - Operações Matemáticas**](questao_03.c)**:** Entrada de dados para cálculo das quatro operações matemáticas básicas (soma, subtração, multiplicação e divisão).
* [**Questão 04 - Operadores Relacionais**](questao_04.c)**:** Leitura de dois inteiros para testar e informar igualdade ou qual dos elementos é maior utilizando lógica relacional.
* [**Questão 05 - Tabela Verdade**](questao_05.c)**:** Validação lógica condicional estruturada com operadores booleanos (`\&\&`, `||`, `!`) para avaliar a aprovação de um discente por média e frequência.

### Módulo 3: Comandos de Entrada e Saída

* [**Questão 06 - Cadastro de Usuário**](questao_06.c)**:** Manipulação de vetores de strings para captura e amostragem de dados cadastrais (nome, idade e cidade).
* [**Questão 07 - Antecessor e Sucessor**](questao_07.c)**:** Captura de um número inteiro e cálculo algébrico simples de seus respectivos vizinhos aritméticos.
* [**Questão 08 - Conversor de Temperatura**](questao_08.c)**:** Algoritmo de conversão térmica de escalas Celsius para Fahrenheit baseado em fórmula matemática.

### Módulo 4: Estruturas de Decisão

* [**Questão 09 - Número Positivo ou Negativo**](questao_09.c)**:** Bloco condicional encadeado (`if-else if`) para classificar um número como positivo, negativo ou nulo.
* [**Questão 10 - Par ou Ímpar**](questao_10.c)**:** Análise de resto de divisão inteira por meio do operador módulo (`%`) para determinação de paridade numérica.
* [**Questão 11 - Média do Aluno**](questao_11.c)**:** Sistema de verificação acadêmica com múltiplos desvios condicionais avaliando status entre aprovado, recuperação ou reprovado.
* [**Questão 12 - Calculadora Simples com Switch**](questao_12.c)**:** Implementação de menu seletor de operações matemáticas utilizando a estrutura de controle de fluxo `switch-case`.

### Módulo 5: Estruturas de Repetição

* [**Questão 13 - Contagem de 1 a 10**](questao_13.c)**:** Laço de repetição determinado com `for` para exibição cronológica de valores numéricos de 1 a 10.
* [**Questão 14 - Tabuada**](questao_14.c)**:** Geração dinâmica e automatizada da tabuada de multiplicação para qualquer número inteiro fornecido via terminal.
* [**Questão 15 - Soma dos Números**](questao_15.c)**:** Implementação de laço contador associado a uma variável de acumulação (soma incremental) para 5 entradas distintas.
* [**Questão 16 - Fatorial**](questao_16.c)**:** Cálculo iterativo do produtório matemático acumulado para definição do fatorial de um número inteiro positivo.

### Módulo 6: Vetores e Matrizes

* [**Questão 17 - Vetor Simples**](questao_17.c)**:** Instanciação e preenchimento estático de indexação para vetor unidimensional contendo 5 elementos informados.
* [**Questão 18 - Maior Elemento do Vetor**](questao_18.c)**:** Varredura indexada via estrutura de repetição em vetor de 10 posições para identificação e isolamento do maior valor e seu índice correspondente.
* [**Questão 19 - Soma de Matriz**](questao_19.c)**:** Alocação bidimensional estática ($2 \\times 2$) e cálculo agregador unificado de todos os elementos da tabela.
* [**Questão 20 - Diagonal Principal**](questao_20.c)**:** Manipulação de matriz quadrada de ordem 3 ($3 \\times 3$) para leitura e filtragem seletiva de saída dos índices onde linha é igual à coluna ($M\[i]\[i]$).
